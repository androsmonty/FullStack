# FullStack Project

A complete full-stack web application template with a modern frontend and backend setup.

## Project Structure

```
FullStack/
├── frontend/          # Frontend application
├── backend/           # Backend API server
├── docs/             # Documentation
└── README.md         # This file
```

## Features

- **Frontend**: HTML, CSS, JavaScript with Bootstrap
- **Backend**: Node.js with Express
- **Documentation**: Complete setup and usage guides

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/androsmonty/FullStack.git
cd FullStack
```

2. Install frontend dependencies:
```bash
cd frontend
npm install
```

3. Install backend dependencies:
```bash
cd backend
npm install
```

### Running the Application

#### Frontend
```bash
cd frontend
npm start
```

#### Backend
```bash
cd backend
npm start
```
