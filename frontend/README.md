# Frontend

This is the frontend application for the FullStack project, built with HTML, CSS, and Bootstrap.

## Features

- Responsive design using Bootstrap 4
- Grid system examples
- Alert components
- Button styles
- Interactive elements

## Structure

- `index.html` - Main HTML file with Bootstrap examples
- `da` - Configuration file

## Getting Started

### Installation

```bash
npm install
```

### Running the Development Server

```bash
npm start
```

This will start a local server on `http://localhost:8080`

### Development Mode

```bash
npm run dev
```

This will start the server and automatically open it in your browser.

## Dependencies

- Bootstrap 4.1.1 (via CDN)
- jQuery 3.3.1 (via CDN)
- Popper.js 1.14.3 (via CDN)

## Browser Support

Works on all modern browsers including:
- Chrome
- Firefox
- Safari
- Edge
